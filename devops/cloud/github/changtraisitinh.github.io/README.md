# changtraisitinh.github.io

Modern landing page showcasing cutting-edge web design with vibrant gradients, smooth animations, and premium aesthetics.

## Features

- 🎨 **Modern Design**: Dark mode with vibrant purple/blue gradients
- ⚡ **Smooth Animations**: Fade-in effects and micro-interactions
- 📱 **Fully Responsive**: Optimized for all device sizes
- 🚀 **Performance**: Fast loading and smooth scrolling
- ♿ **Accessible**: Semantic HTML and ARIA labels
- 🔍 **SEO Optimized**: Meta tags and proper heading structure

## Local Development

To run the landing page locally:

```bash
# Navigate to the project directory
cd changtraisitinh.github.io

# Start a local server (Python 3)
python3 -m http.server 8000

# Or use Node.js
npx serve

# Open in browser
# http://localhost:8000
```
