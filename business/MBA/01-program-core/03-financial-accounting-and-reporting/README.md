# Financial Accounting and Reporting

**Mã môn**: MBA4002 | **L-T-P-C**: 3-1-0-4

**Nguồn bổ sung**: [`Aurora-PG-College-MBA-Semester-1-Handbook-2025-2026.pdf`](../../Aurora-PG-College-MBA-Semester-1-Handbook-2025-2026.pdf) — môn MB102 "Accounting for Management" (5 unit + session plan + question bank thật).

## Nội dung chính

_(chưa tổng hợp chi tiết — 5 unit tham khảo từ MB102)_

- Unit I: Nhập môn kế toán tài chính — hệ thống ghi sổ kép, Journal/Ledger/Trial Balance, chuẩn mực kế toán (IFRS)
- Unit II: Lập báo cáo tài chính — phân biệt capital/revenue expenditure, khấu hao, Trading/P&L/Balance Sheet
- Unit III: Phân tích báo cáo tài chính — phân tích tỷ số (thanh khoản, hoạt động, sinh lời, đòn bẩy)
- Unit IV: Báo cáo lưu chuyển tiền tệ, hoạch định thuế, phân loại chi phí
- Unit V: Phân tích CVP (điểm hoà vốn), Standard Costing, phân tích biến động chi phí
